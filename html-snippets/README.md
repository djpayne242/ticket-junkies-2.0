# TicketJunkies HTML snippets for WordPress

These work **after the TicketJunkies plugin is installed and activated**. Each file has two versions of the same thing. Use whichever is easier:

1. **Shortcode:** paste it into a *Shortcode* widget (Elementor) or a *Shortcode* block (WordPress editor).
2. **HTML:** paste it into an *HTML* widget (Elementor) or a *Custom HTML* block (WordPress editor).

The plugin already creates all of these pages for you. Use the snippets only when you want to place a piece somewhere else, for example the event grid on another page.

| File | What it shows |
|---|---|
| `00-hero-box.html` | Orange & blue "Get your ticket fix." box with search, weather and clock inside |
| `01-homepage-complete.html` | Complete homepage (hero, search, weather & clock, categories, map, event grid) |
| `02-search-bar.html` | Search bar |
| `03-weather-and-clock.html` | Slim clock & weather bar (put it above the hero box) |
| `04-become-organizer-button.html` | "Become an organizer" call-to-action |
| `05-category-buttons.html` | Category buttons (Music, Nightlife, Comedy…) |
| `06-events-map.html` | Live events map |
| `07-event-grid.html` | Upcoming events grid |
| `08-calendar.html` | Calendar of events (current month, event days highlighted) |
| `10-event-page.html` | Event details & ticket picker (put on the "event" page) |
| `11-checkout.html` | Checkout (put on the "checkout" page) |
| `12-my-tickets-dashboard.html` | Attendee ticket dashboard (put on the "my-tickets" page) |
| `13-organizer-dashboard.html` | Organizer dashboard (put on the "organizer" page) |
| `14-admin-panel.html` | Admin Panel (put on the "ticket-admin" page) |
| `15-login-form.html` | Log in form (put on the "login" page) |
| `16-create-account-form.html` | Create account form (put on the "register" page) |
| `17-ticket-viewer.html` | Ticket viewer for email/text links (put on the "ticket" page) |

**Extra options for the event grid:** `[ticketjunkies widget="grid" title="Nightlife this month" category="Nightlife" limit="6" columns="3"]`

You can change colors, fonts, corners and shadows in Elementor's **Style** tab when you use the 🎟️ TicketJunkies widgets instead of HTML.
